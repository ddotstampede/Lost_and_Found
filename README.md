# Lost & Found

## Kurzbeschreibung

**Lost & Found** ist eine einfache C#-Konsolenanwendung zur Verwaltung eines Fundbüros.

Mit dem Programm können:
- Kunden und Mitarbeiter angelegt werden
- Verlust-Tickets erstellt und geschlossen werden
- Fundstücke erfasst werden
- offene Tickets mit Fundstücken abgeglichen und Kunden bei einem Treffer benachrichtigt werden
- alle gespeicherten Daten übersichtlich angezeigt werden

Zusätzlich enthält das Projekt die Planungsdokumente sowie ein SQL-Skript für die dazugehörige Datenbank.
